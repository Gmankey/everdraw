# Developers

Technical documentation for integrating with EverDraw V5 or building on top of its public interfaces.

The current release target is the V5 continuous TWAB stack. The authoritative list of deployed addresses is the [deployment manifest](https://github.com/Gmankey/everdraw/blob/staging/deployments/monad-mainnet.json).

* [Architecture](/developers/architecture) — V5 contracts, services, and draw lifecycle.
* [Smart Contracts](/developers/smart-contract) — V5 entry points, payout model, and events.
* [Version Updates](/developers/version-updates) — V5 behavior and retired-version status.
* [Keeper](/developers/keeper-bot) — managed lifecycle automation and monitoring.
* [Integration Guide](/developers/integration) — deployment scoping, positions, events, and indexer usage.
* [Draw Algorithm](/developers/draw-algorithm) — deterministic winner and Merkle-root construction.
