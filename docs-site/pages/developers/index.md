# Developers

Technical documentation for integrating with EverDraw or building on top of it.

The current production contract is `TicketPrizePoolV4`. The authoritative list of deployed addresses is the [deployment manifest](https://github.com/Gmankey/everdraw/blob/staging/deployments/monad-mainnet.json).

* [Architecture](/developers/architecture) — system overview and data flow.
* [Smart Contract](/developers/smart-contract) — V4 interface: constructor, functions, events, and the Merkl surface.
* [Keeper Bot](/developers/keeper-bot) — round automation and the lifecycle actions.
* [Integration Guide](/developers/integration) — reading round data, listening for events, and the indexer API.
