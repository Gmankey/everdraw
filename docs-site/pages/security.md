# Security

## Audit status

EverDraw has not yet completed a formal third-party audit.

Until that is complete, users should treat the product carefully and avoid depositing more than they are comfortable with.

---

## What has been tested

- unit and integration testing
- full round lifecycle testing
- keeper flow testing
- ShMON integration testing
- public contract verification

---

## Key properties

**No principal loss by design**

EverDraw is designed so user principal is tracked separately from prize yield.

**No upgrade proxy**

The deployed contract is not intended to be silently changed through an upgrade proxy.

**Public on-chain logic**

The contract code and draw logic are publicly inspectable.

---

## Verified source

The smart contract source is publicly verifiable on Monad's explorer.

---

## Responsible disclosure

If you discover a vulnerability, contact the team privately before disclosing it publicly.
