# The Vision

> Prize savings infrastructure for all of Monad.

EverDraw launches as a MON prize vault. That is the wedge, not the destination.

The roadmap builds from a single product into ecosystem wide prize infrastructure, a protocol layer where any asset, any protocol, and any campaign can plug into prize mechanics. For users, it is the simplest way to save with upside. For protocols, it is a retention engine that replaces one shot airdrops with recurring engagement.

---

## The arc

**Product → Continuous + Campaigns → Multi Asset → Platform → Infrastructure**

| Phase | Milestone | Focus |
|---|---|---|
| 1 | Launch | Prove the core loop. First real winners. |
| 2 | Continuous + Campaigns | TWAB deposits. CampaignManager for protocols. |
| 3 | Multi Asset + Ecosystem | Stablecoin vaults. Cross protocol mega draws. Points layer. |
| 4 | Platform | Permissionless vault factory. Protocol revenue. |
| 5 | Infrastructure | SDK. Cross chain deposits. Autonomous operation. |
