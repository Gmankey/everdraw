# EverDraw UI Requirements

- Do not make unsolicited design/copy changes. Preserve existing layout unless explicitly asked.
- Previous Vault is global: it links to the latest completed historical round and must not be greyed out by switching Vault A/B.
- When Previous Vault is selected, the left card remains the existing purchase-ticket card only; do not replace it with status/summary rows. The buy button is disabled for historical rounds.
- The right vault card for Previous Vault should be minimal and only provide the See Winners entry point.
- User-facing copy must not say "failed"/"Round Failed" for draw issues. Use "Round skipped" / skipped-style language.
- My Rounds actions must be terse: Deposit, Redeem, Claimed, or blank/— only.
